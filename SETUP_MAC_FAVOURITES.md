# Setup Gradlify Demo Video in Mac Finder Favourites

## Automated Setup (Run Once)

```bash
cd ~/Downloads/Projects/Gradlify  # Or wherever your GRADLIFY favourites folder is
cp "Codes/Gradlify demo video.mp4" . 2>/dev/null || cp "11+ GRADLIFY/Gradlify demo video.mp4" . 2>/dev/null || cp "GRADLIFY APP CODES/11+ GRADLIFY/Gradlify demo video.mp4" .
open -R "Gradlify demo video.mp4"
```

## What This Does

1. Navigates to your GRADLIFY Finder favourites folder
2. Copies the demo video from the repo subfolder to the top level (same folder as Gradlify-Partner-Overview.pptx)
3. Reveals the video in Finder

## Expected Result

Your GRADLIFY favourites folder will contain:
- Codes/ (or 11+ GRADLIFY/)
- Gradlify-Partner-Overview.pptx
- 11+ 14th June Mock Poster.jpeg
- **Gradlify demo video.mp4** ← NEW

File location: `~/Downloads/Projects/Gradlify/Gradlify demo video.mp4`
