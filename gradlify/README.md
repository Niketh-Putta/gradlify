# Gradlify demo video

**File:** `Gradlify demo video.mp4` - investor product walkthrough (final cut only).

## Open on your Mac

1. Pull latest code in this repo (`git pull`).
2. **Easiest:** In Finder, go to this `gradlify` folder and **double-click** `Open in Finder.command`.
3. **Terminal** (from repo root):

```bash
open "gradlify/Gradlify demo video.mp4"
```

Or reveal the folder:

```bash
open "gradlify"
```

## Repo path (relative)

```
gradlify/Gradlify demo video.mp4
```

On Niketh's machine the repo usually lives under **Finder → Favourites → Gradlify** (e.g. `~/Downloads/Projects/Gradlify/.../11+ GRADLIFY/`). Use the script above so the path always resolves from this folder.
